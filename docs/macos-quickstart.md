# VeniMapping macOS Development Setup Guide

## Overview

This guide explains how to set up the VeniMapping development environment on a Mac. You will use a Visual Studio Code (VS Code) Dev Container to provide the Linux-based development environment required by the project.

Instead of installing ROS 2 and the camera-driver dependencies directly on your Mac, you will use Docker to run a preconfigured Linux environment.

By the end of this guide, you should be able to:

1. Open the VeniMapping repository in VS Code.
2. Start the development container.
3. Verify that ROS 2 Jazzy and the camera-driver environment are available.
4. Build the ROS 2 workspace.
5. Run the project's IDE setup and code-quality checks.

## Prerequisites

Before starting, ensure you have:

1. An Apple Silicon Mac.
2. Docker Desktop for Mac installed and running.
3. Visual Studio Code installed.
4. The Microsoft Dev Containers extension installed in VS Code.
5. Git installed.
6. Access to the VeniMapping Git repository.

## Get the Repository

First, clone the VeniMapping repository into your desired directory using a terminal:

```bash
git clone https://github.com/lkaising/venimapping.git
cd venimapping
```

If you already have the repository on your Mac, open the existing directory instead of cloning it again.

To confirm that you are in the project directory, run:

```bash
pwd
ls -la
```

You should see the project files and directories, including `.devcontainer`.

## Open the Project in the Development Container

1. Open VS Code.
2. Select **File → Open Folder**.
3. Choose the local VeniMapping repository directory.
4. Open the Command Palette using **Cmd + Shift + P**.
5. Search for **Dev Containers: Reopen in Container** and select it.
6. Wait for the container image to build and the development container to start.

During the initial build, keep VS Code open. If VS Code prompts you to install recommended extensions, allow the installation if appropriate.

Once the process finishes, the project should reopen inside the container, with the working repository located at:

```text
/home/dev/workspace/project/venimapping
```

## Verify the Environment

Open a new terminal in VS Code. Make sure you are in the repository root:

```bash
cd /home/dev/workspace/project/venimapping
```

Activate the project's environment:

```bash
source scripts/env.sh
```

Confirm that the output indicates:

- ROS 2 Jazzy is active.
- The Vimba ROS 2 driver is active.
- GenTL is active.
- Cyclone DDS is selected as the ROS middleware.

If any component is missing or inactive, resolve the environment issue before continuing.

## Build the Workspace

From the repository root, run:

```bash
colcon build --symlink-install
```

This command builds the ROS 2 packages in the workspace.

Confirm that the command completes successfully and that the final build summary reports both `venimapping_bringup` and `venimapping_camera` as finished.

Warnings may appear during compilation. A warning alone does not necessarily indicate failure; check the final summary and the command's exit status.

## Configure IDE Support

After a successful build, run:

```bash
./scripts/ide.sh
```

This script prepares the project's IDE configuration using the compilation database and other information generated by the build.

Confirm that the script exits successfully. In VS Code, check that the editor can resolve headers for `rclcpp` and `vimbax_camera_msgs`.

## Run the Code-Quality Check

From the repository root, run:

```bash
./scripts/tidy.sh check
```

Confirm that the script exits successfully and reports no findings.

## Troubleshooting

### The development container fails to start

- Confirm that Docker Desktop is running.
- Review the container build output for errors.
- Retry opening the project in the Dev Container after resolving any errors.

### ROS 2 or driver components are missing

From the repository root inside the container, run:

```bash
source scripts/env.sh
```

Review the environment status before retrying the build.

### The workspace build fails

Review the first relevant compiler or CMake error in the output. Resolve the underlying issue, then rerun:

```bash
colcon build --symlink-install
```

### VS Code cannot resolve ROS 2 headers

Confirm that the workspace build and IDE setup completed successfully. Then reopen the relevant source file and check the editor's diagnostics.

## Final Verification Checklist

Before considering the setup complete, confirm that:

- [ ] The development container opens successfully.
- [ ] The environment script reports ROS 2 Jazzy, the driver, GenTL, and Cyclone DDS as expected.
- [ ] `colcon build --symlink-install` completes successfully.
- [ ] `./scripts/ide.sh` completes successfully.
- [ ] `./scripts/tidy.sh check` completes successfully with no findings.
- [ ] VS Code resolves `rclcpp` and `vimbax_camera_msgs`.
- [ ] The camera driver passes the project's simulator verification.
- [ ] The setup instructions have been tested by another person on a clean Mac.
