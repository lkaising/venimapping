## Task: review the sections of the other planner

Read the {other} sections in `{P}/{other}/sections/`, the file
`{P}/{other}/source-tree.md`, and the file `{P}/{other}/draft-notes.md`. Also
read the register, the facts, the code, and your own sections, so that you can
check that the interfaces match.

Write `{P}/{tool}/review-of-{other}.md`. List the findings in a table with the
columns Id, Severity, Section, Location, Finding, Evidence, and Suggested fix.

1. Use these severity values. Blocking means that the design would not work or
   contradicts the register. Major means a real gap or an incorrect claim.
   Minor means a small error that changes the meaning.
2. Use the ids r-{tool}-1, r-{tool}-2, and so on.
3. Do not report wording or style. The coordinator does the prose pass.
4. Check each citation that a finding relies on.

End with a list of the interface mismatches between your sections and theirs.
